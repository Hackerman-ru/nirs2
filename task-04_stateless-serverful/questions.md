# Вопросы по статье "Boki: Stateful Serverless Computing with Shared Logs"

### Выполнил Корняков Санан Арсланович

## Описание

Статья описывает исследовательскую платформу Boki для Stateful Serverless сервисов. Основная идея - использовать распределённые логи для хранения, восстановления и выполнения транзакций над текущим состоянием.

## Вопросы

- Как Boki решает проблему усечения общего журнала при наличии медленных потребителей: кто определяет безопасную точку truncate, как предотвращается раздувание хранения, и какой накладной ценой (чекпойнты, write amplification) это достигается?

- Какие механизмы обеспечения детерминизма предусмотрены для корректного реплея (учет времени, случайности, внешних вызовов), и каков разработческий «налог» на использование этих механизмов?

- Какие end-to-end гарантии «ровно-однажды» возможны при взаимодействии с внешними системами вне журнала, и предоставляет ли Boki встроенные паттерны (например, outbox/inbox) для безопасной интеграции?
