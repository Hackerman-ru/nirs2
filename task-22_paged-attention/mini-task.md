# Мини-задание по статье "Efficient Memory Management for Large Language Model Serving with PagedAttention"

### Выполнил Корняков Санан Арсланович

## Описание статьи

Статья описывает PagedAttention — блочную организацию KV‑кэша внимания с табличной адресацией блоков по аналогии с виртуальной памятью в ОС. Блоки фиксированного размера выделяются по мере роста последовательности, могут храниться несмежно и шариться между последовательностями с copy‑on‑write для изменяемых хвостов. На базе этого построен vLLM, который почти устраняет потери памяти под KV‑кэш и увеличивает пропускную способность в 2–4 раза по сравнению с аналогами при сопоставимых задержках.

## Слабые стороны и ограничения подхода PagedAttention

### Нерегулярный доступ к памяти и накладные расходы в ядрах внимания

Блочный доступ по таблице отображений ухудшает coalesced memory access и добавляет лишние ветвления. В статье ядро attention становится медленнее на 20–26%. При коротких последовательностях и малых батчах выигрыш от лучшего батчинга может не перекрывать оверхед.

*Решение:* гибридный режим исполнения — при малых батчах/контекстах использовать последовательную версию attention, автотюнинг конфигурации ядра и размера блока, переупорядочивание идентификаторов блоков для повышения локальности.

### Чувствительность к размеру блока и изменчивые нагрузки

Большие блоки улучшают параллелизм, но повышают внутреннюю фрагментацию и снижают вероятность шаринга, маленькие — наоборот. Оптимум зависит от текущего распределения длин запросов и настроек декодирования, которые меняются во времени.

*Решение:* онлайн‑автотюнинг размера блока под целевую метрику (throughput/SLO), пулы блоков нескольких размеров с назначением мелких блоков коротким запросам. Ограниченная фоновая перепаковка только хвостовых блоков.

### Вытеснение: выбор между swap и пересчётом

Swapping упирается в пропускную способность PCIe/NVLink и особенно неэффективен при мелких блоках. Пересчёт тратит GPU и может быть дорогим при очень длинных префиксах. Неверный выбор стратегии увеличит хвостовые задержки.

*Решение:* гибридная политика на основе онлайн‑оценки стоимости swap/recompute с учетом топологии и размеров, сжатие KV при свопе с контролем потерь.
